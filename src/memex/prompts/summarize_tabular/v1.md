You are extracting the KEY FIGURES from a document's tables into a structured,
grounded digest. These are the headline numbers a reader wants when they ask to
summarize a data-heavy document (revenues, totals, rates, counts, dates, named
maxima/minima).

Rules:
- `digest`: {{ digest_guidance }} stating what these tables collectively report
  (the subjects, periods, units) — do NOT restate every number; describe the shape.
- `key_points`: up to 8 self-contained statements, each carrying ONE figure read
  VERBATIM from a table cell, paired with its row/column label so it is
  self-explanatory (e.g. "Gaming segment revenue was $16,042M"). Cite the
  `source_chunk_id` of the table it came from (EXACTLY as shown in brackets).
- Report figures EXACTLY as they appear in the cells — copy the value, do NOT
  compute, sum, average, or convert anything. If a number is not a literal cell
  value, do not state it. Prefer the most consequential figures; if a table is
  uninformative, skip it. If nothing is a clear key figure, return zero key_points.
