You are extracting the KEY FIGURES from a document's tables into a structured,
grounded digest. These are the headline numbers a reader wants when they ask to
summarize a data-heavy document (revenues, totals, rates, counts, dates, named
maxima/minima).

Rules:
- `digest`: {{ digest_guidance }} stating what these tables collectively report
  (the subjects, periods, units) — do NOT restate every number; describe the shape.
- `key_points`: up to 8 self-contained statements, each carrying ONE figure read
  VERBATIM from a table cell BELOW. Name BOTH what the figure measures AND its
  period/column so it is unambiguous — phrase each as "<what the row/column
  measures> for <its period or category> was <the exact cell value>", NOT a bare
  "label=value". Keep the row's own label with its value, and cite the
  `source_chunk_id` of the table it came from (EXACTLY as shown in brackets). Use
  ONLY values that literally appear in the cells below: do NOT reproduce the
  placeholder wording above, and NEVER import or invent a figure that is not in
  these cells (no numbers from memory or from these instructions).
- Skip a row that is just an entity/index name paired with a bare number and no
  clear metric (e.g. a stock-performance-graph row pairing a company name with a
  share price) — that value is not a self-explanatory key figure.
- Report figures EXACTLY as they appear in the cells — copy the value, do NOT
  compute, sum, average, or convert anything. If a number is not a literal cell
  value, do not state it. Prefer the most consequential figures; if a table is
  uninformative, skip it. If nothing is a clear key figure, return zero key_points.
